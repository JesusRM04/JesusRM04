> **Proyecto Institucional | INFOTEC | Repositorio Privado**

Sistema web desarrollado para centralizar y digitalizar la gestión académica de estudiantes de programas de posgrado. Permite administrar información de estudiantes de maestría y doctorado, dar seguimiento a procesos de titulación, gestionar documentación y generar información para consulta y seguimiento institucional.

#### Funcionalidades
- Gestión de estudiantes de posgrado y seguimiento de procesos académicos y de titulación.
- Administración de usuarios, roles, control de permisos de acceso y autenticación con 2FA.
- Gestión y digitalización de documentos e importación masiva de información.
- Generación de reportes, registro y consulta de auditoría y monitoreo de información en tiempo real.

#### Stack Tecnológico

* **Infraestructura:** Docker, Docker Compose, PostgreSQL, Mailpit, Git

#### Mi Participación
Desarrollo full-stack del sistema, trabajando en componentes de frontend, lógica de backend, APIs, integración con PostgreSQL y funcionalidades de autenticación, usuarios, roles y permisos. Integración y configuración del entorno de desarrollo mediante contenedores Docker.

### Clasificación y Análisis de Texto
> **Proyecto Institucional | Aplicación Web**

Aplicación web orientada al análisis automático de textos en español mediante técnicas de procesamiento de lenguaje natural y modelos de clasificación. Integra una API desarrollada en Python con una interfaz web para procesar texto y obtener diferentes resultados de análisis.

#### Funcionalidades
- Análisis de sentimiento y clasificación de texto.
- Identificación de dialectos del español y generación de caracteres asociados al contenido analizado.
- Procesamiento de texto mediante modelos de NLP.
- Comunicación frontend/backend mediante API REST y almacenamiento de resultados.

#### Stack Tecnológico
* **Backend:** Python, Flask, Flask-CORS
* **Procesamiento NLP:** EvoMSA, DenseBoW, DialectId
* **Frontend:** HTML5, CSS3, JavaScript ES6, Bootstrap 5
* **Base de Datos:** Firebase Realtime Database

#### Mi Participación
Desarrollo de la aplicación web y API REST, integración de las herramientas de procesamiento de lenguaje natural, comunicación entre frontend/backend y almacenamiento de resultados mediante Firebase.
